Smart Study Planner 📚

A beginner-friendly Python project designed to organize and manage study tasks.

 Features
- Add study tasks
- View all tasks
- Set due dates
- Assign task priorities (High, Medium, Low)
- Mark tasks as completed
- Delete tasks
- Save and load tasks using JSON file handling

 Technologies Used
- Python
- JSON
- VS Code

 Concepts Learned
- Variables and data types
- Lists and dictionaries
- Loops and conditional statements
- Exception handling
- File handling
- JSON module
 How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run the Python file.

 Future Improvements
